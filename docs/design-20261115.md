Intent: turn the existing three-app source directory into an organized software product shelf without suggesting ratings, safety guarantees or automatic downloads. Routine design decisions were delegated.

Direction: a dark tool-window hero with original generic utility line icons, pale lilac workspace, large original monogram badges and rounded product dossiers that separate purpose, platforms and cost scope. No vendor logo, screenshot or invented app fact is used. Existing official links, caveats, descriptions, prices and verification dates remain intact.

Plan: fresh SHA-verified remote snapshot/no open PR; fail new presentation-hook test; add versioned local CSS and decorative SVG; preserve active scripts/data and IDs; static preservation and DOM search/platform/category/reset regressions; expected-head publish; Pages/public-byte verification and responsive visual QA. No tracking or external dependencies.
